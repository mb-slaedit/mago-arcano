# 🔮 Mago Arcano

Jogo de magias por gestos (PC com câmera) e com botões touch (celular).

Jogue online: ative o **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / `/ (root)`) e abra o link do repositório.

- `pc.html` — versão PC (câmera + teclado)
- `celular.html` — versão mobile (touch)
